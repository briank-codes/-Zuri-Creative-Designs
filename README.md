# Zuri Creative Designs

Zuri Creative Designs is a web design agency based in Nyahururu, Kenya, serving local and international clients. This repository contains the agency's official portfolio site — a clean, minimal, black/white/deep-green branded experience showcasing our services.

## Services

- Full-stack web development
- Mobile app development
- Branding
- SEO
- WiFi billing systems

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **UI Library:** React 19
- **Styling:** Tailwind CSS 4
- **Icons:** lucide-react
- **Contact Form:** Web3Forms

## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
